# HSK Слова

Программа для Mac: карточки, повторения и тесты по словам **HSK 3.0**. Слова уже внутри. После установки интернет, терминал и Node.js не нужны.

## Как открыть на Mac

Это делает тот, кто будет учить слова. Ничего устанавливать заранее не надо.

1. Возьмите файл `HSK Slova-….dmg` (его собирают один раз, см. ниже, либо скачивают из артефактов GitHub Actions).
2. Откройте файл двойным щелчком.
3. Перетащите **HSK Slova** в папку **Программы**.
4. Откройте программу. В окне будет написано **HSK Слова**.
5. Если Mac пишет, что разработчик неизвестен: щёлкните по значку **правой кнопкой** → **Открыть** → ещё раз **Открыть**. Либо: Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**. Это обычная проверка, программа не из App Store и без платной подписи Apple.
6. Дальше можно заниматься без интернета. Прогресс хранится на этом компьютере.

Начните с уровня **HSK 1** — он уже выбран. Крупный иероглиф, кнопка **Показать ответ**, затем **Не знаю / Трудно / Знаю / Легко**. Кнопки **A−** и **A+** меняют размер текста.

В тестах вопросы каждый раз собираются заново из списка. Готового набора билетов нет.

Значения слов показаны **по-английски**: так они даны в открытом списке. Полного русского перевода всего перечня HSK 3.0, который можно было бы законно вложить в программу, нет, поэтому программа его не выдумывает. Кнопки и подписи — по-русски.

## Откуда слова

11 000 слов официального экзаменационного перечня HSK 3.0 (考试大纲, ноябрь 2025) в открытой публикации Gushi:

[HSK 3.0 word list by Gushi](https://gushichinese.com/hsk-3.0/downloads), лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

- Английские значения — из [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) (тоже CC BY-SA 4.0).
- Примеры, где они есть, в основном из [Tatoeba](https://tatoeba.org) (CC BY 2.0 FR).
- Подробности и что именно изменено при упаковке: [data/ATTRIBUTION.md](data/ATTRIBUTION.md).

Числа по уровням такие, как в этом перечне, а не «примерно»:

| Уровень | Слов |
| --- | ---: |
| HSK 1 | 300 |
| HSK 2 | 200 |
| HSK 3 | 500 |
| HSK 4 | 1 000 |
| HSK 5 | 1 600 |
| HSK 6 | 1 800 |
| HSK 7–9 | 5 600 |

Полоса **7–9** в экзамене одна. В данных Gushi она разрезана на три учебные части примерно по 1 867 слов, чтобы было куда двигаться дальше. В программе можно выбрать весь экзамен «7–9» или часть 1, 2, 3. Это деление составителя списка, не отдельный официальный экзамен.

Обновить словарь из того же источника:

```bash
node scripts/prepare-words.mjs
```

## Как устроены занятия

- **Уровень** — полоса HSK. **Какие слова** — личная сложность: новые, лёгкие, средние, сложные.
- **Карточки.** Сначала то, что пора повторить, потом порция новых. «Не знаю» возвращает слово в ту же серию.
- **Повторения** — вариант SM-2. «Не знаю» снижает лёгкость и ставит слово на повтор через 10 минут. «Знаю» уводит его на 1 день, потом на 6, дальше интервал растёт. «Легко» удлиняет шаг, «Трудно» — короче и осторожнее.
- **Сложное** — последний ответ был «Не знаю», либо слово всё ещё даётся тяжело. Фильтр «Сложные» и отдельный экран показывают только их, даже если срок повторения ещё не наступил.
- **Выучено** — ответы уже уверенные и следующий показ не раньше чем через 21 день. **Повторяется** — слово уже открывали, но до «выучено» ещё далеко.
- **Тест** собирается из текущего фильтра: значение, пиньинь, иероглиф, пропуск в предложении (как в заданиях Boya, если у слова есть пример). Чужие варианты берутся из слов того же уровня, по возможности похожих. «Новый тест» собирает другой набор. Можно вписать пиньинь латиницей: тон можно не ставить, правильный тон программа покажет. Ошибки теста тоже попадают в повторения.
- **Прогресс** можно сохранить в файл и загрузить на другом компьютере.

Озвучка — голос macOS «Китайский (упрощённый)», если он установлен. Без него кнопки всё равно работают.

## Как собрать установщик

Нужен компьютер Mac (Apple Silicon или Intel) и [Node.js 22](https://nodejs.org). Это делает человек, который готовит программу, не тот, кто по ней занимается.

```bash
npm install
npm test
npm start
npm run dist:mac
```

`npm start` открывает окно для проверки. `npm run dist:mac` кладёт универсальный `.dmg` и `.zip` (Apple Silicon и Intel в одном файле) в папку `release/`. Подпись Apple не используется: `CSC_IDENTITY_AUTO_DISCOVERY=false` уже стоит в команде.

Если универсальный файл на этом Mac не собирается:

```bash
npm run dist:mac:arm
npm run dist:mac:intel
```

Тот же установщик можно собрать в GitHub Actions: вкладка Actions → **macOS app** → Run workflow. Готовый `.dmg` будет в артефактах. Тег `v*` запускает сборку сам.

Если macOS после скачивания говорит, что файл повреждён, это часто карантин неподписанной программы. На Mac того, кто помогает с установкой:

```bash
xattr -dr com.apple.quarantine "/Applications/HSK Slova.app"
```

## Что в папках

- `electron/` — окно Mac, меню по-русски, сохранение прогресса в папке пользователя
- `src/` — экран, карточки, тесты
- `src/lib/` — SM-2, фильтры, сборка вопросов (без интерфейса, их проверяют тесты)
- `data/hsk30.json` — вложенный список слов
- `scripts/prepare-words.mjs` — заново скачать и упаковать список
- `test/` — проверки алгоритма, списка и окна
